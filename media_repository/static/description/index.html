Frequently Asked Questions

What types of media assets can be managed using this module?

The Media Repository module supports managing images, videos, documents, audio files, and external URLs. Users can upload, organize, and access all media assets from a centralized repository.

How can users organize media assets?

Users can organize media assets using categories and tags. This helps in maintaining a structured repository and makes it easier to locate files when needed.

Can users search and filter media assets?

Yes. The module provides advanced search, filtering, and grouping options. Users can quickly find assets based on media type, category, tags, and other criteria.
