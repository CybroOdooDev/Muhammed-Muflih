Media Repository

The Media Repository module provides a centralized platform for storing, organizing, and managing media assets within Odoo. Users can upload files, categorize them, search efficiently.

Key Highlights

Users can upload files or urls.

Quickly find media assets using advanced search, filters, and grouping options based on media type, category.

View a summary of your uploaded media assets with category-wise counts for quick access and management.

User Groups

There will be two user groups user and manager.


Dashboard

View a summary of your uploaded media assets with category-wise counts for quick access and management.


Upload Files

Users can upload files, assign categories, add descriptions and tags, and manage media assets from a single centralized location.


Uplad Urls

Users can upload url, assign categories, add descriptions and tags.


Media Category

configuration > media category, users can create categories.


Media Tag

Configuration > Media Tag, users can create tags.


Search Records

Quickly find media assets using advanced search, filters, and grouping options based on media types, category.


Users can quickly search using media types filters such as video,image,url,document.


Users can organize their assets using the Group By filter. Assets can be grouped based on criteria such as Media Type and Media Category, making it easier to manage, browse, and locate media files efficiently.


  • Manage images, videos, documents, audio files, and external URLs from a single, organized repository.
  • Organize media assets using categories and tags to maintain a structured library and quickly locate files.
  • Find media assets easily with powerful search, filtering, and grouping options based on media type, category, tags, and other criteria.
  • View and manage media assets through a dashboard that provides category-wise asset statistics and an overview of the repository for quick access and management.
