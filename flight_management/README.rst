Flight Management
=================
* This module provides the core foundation for Flight Operations in Odoo. It
  enables the management of aircraft, aircraft makes, models and classes,
  aerodromes, flight records, and flight events. It also includes flight
  lifecycle management, timestamped operational events, role-based security,
  automated sequence generation, and reference data required by other Flight
  Operations modules.
