Age Restricted Products POS
===========================
This module helps to restrict age-restricted products in Point of Sale by prompting the cashier for confirmation before adding them to an order.

Key Features
------------
* Enable age restrictions directly on product templates.
* Automatic verification prompt when adding restricted products in POS.
* Allows cashiers to approve or reject adding the product to the order line.

Installation
------------
No external dependencies.

Configuration
=============
1. Navigate to Point of Sale or Sales > Products > Products.
2. Open any product that is marked as "Available in POS".
3. Under the Sales tab, locate the "Age Restriction" section.
4. Check the "Is Age Restricted" checkbox and save.
