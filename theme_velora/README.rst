Theme Flynova
==============

Theme Velora is an Odoo Website theme designed for modern eCommerce and business websites.It features stylish
shop pages, wishlist support, seamless checkout and order confirmation flows, and reusable website snippets.
The fully responsive design ensures a smooth user experience across all devices.


Configuration
=============

* No additional configuration is required after installation.
